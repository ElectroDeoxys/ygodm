# Yu-Gi-Oh! Duel Monsters

This is a disassembly of Yu-Gi-Oh! Duel Monsters.

It builds the following ROM:

- Yu-Gi-Oh! Duel Monsters (Japan) (SGB Enhanced).gb `sha1: 07ae4a6437f00f6af462bf84fd0ac1cf345c8365`

To assemble, first install [RGBDS](https://github.com/gbdev/rgbds/releases) and put it in your path.  
Then copy the above ROM to this directory as "baserom.gb".  
Then run `make` in your shell.
